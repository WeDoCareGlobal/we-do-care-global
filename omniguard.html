Five Inspection Layers

Each layer is a modular, independently testable security component. All can be enabled independently.

🛡

WAF

Web Application Firewall with 5 regex injection categories: directive override, credential leak, tool hijacking, base64 smuggling, and authority spoofing.

Explore Source ↗
🔕

Trust Boundary

Enforces context separation between user, agent, and tool tiers. Prevents unauthorized escalation between trust levels.

Explore Source ↗
🔐

Agent Vault

Zero-trust secrets lifecycle with AES-256-GCM envelope encryption, auto-expiring leases, and hardware security module integration.

Explore Source ↗
📄

Governance Signer

API-integrity signatures for every request and response. Tamper-evident audit trails with HMAC chaining.

Explore Source ↗
📋

Audit Log

HMAC-chained, immutable audit log with full event provenance. Centralized event emitter with structured output.

Explore Source ↗
📋

Policy Engine

Declarative YAML policy engine with cross-tier decision points, forced-denial overrides, and enforcement levels.

Explore Source ↗

Production Gateway

FastAPI-based request inspection and governance gateway. Deploy as a standalone service or Docker container.

🚀

FastAPI App

REST API with /v1/guard, /v1/sign, /health, and /metrics endpoints. CORS configured, rate-limited, and OpenTelemetry-ready.
